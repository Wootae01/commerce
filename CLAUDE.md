## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues (Wootae01/commerce), managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

No triage labels; only GitHub's default labels (`question` for needs-info, `wontfix`, plus type labels like `bug`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` + `docs/adr/`. See `docs/agents/domain.md`.
